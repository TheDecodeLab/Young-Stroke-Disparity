## Verified public routing and policy

- [Penn State CTSI TriNetX information and support](https://ctsi.psu.edu/services/research/trinetx) lists **ctsi@psu.edu** for technical assistance and a service request for query help. This is a **routing contact**, not evidence that CTSI itself may approve publication or certify aggregate release.
- [TriNetX publication guidelines](https://trinetx.com/publication/trinetx-publication-guidelines/) require naming the specific data network, noting the data analysis or download date, evaluating whether the appropriate network is publishable under HCO agreements, avoiding HCO-specific data, and checking additional terms for third-party-funded research. The specific HCO count and network size require export-specific documentation. Do not copy generic IRB exemption language as the investigator's own study determination.
- [Penn State Human Research Protection Program](https://researchsupport.psu.edu/orp/irb/irb-basic-steps/step-1-is-it-human-subjects-research/) describes the distinction between IRB review and an official non-human-subjects determination. The actual study-specific institutional determination has not been inspected here.
